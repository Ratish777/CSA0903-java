## Compile and run
Open the relevant task folder in IntelliJ IDEA. For a standalone Java file with no external libraries, open the file and click Run, or use:

```bash
javac FileName.java
java ClassName
```

For GUI tasks run on a desktop with a graphical environment. CO4 Task06 and CO5 database tasks require MySQL and a JDBC driver (for example, MySQL Connector/J); set `JDBC_URL`, `JDBC_USER`, and `JDBC_PASSWORD` environment variables for the CO4 application.
